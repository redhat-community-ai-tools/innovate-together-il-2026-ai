# Leveraging Sandboxing and Confidential Computing for Agents and Models

**12:50** · [Ariel Adam](https://www.linkedin.com/in/ariel-adam-26398b55/) (Red Hat)

Kata-based agent sandboxes and confidential containers + KServe for confidential inference — protect agents, models, and data.

**Takeaways**

- Separate agent execution sandbox from model confidentiality — different threats
- Prefer Kata / confidential containers over trusting the host-admin boundary alone
- Ask for attestation / key-release when models or prompts must stay confidential on shared infra

**Docs / projects:** [Kata](https://katacontainers.io/) · [Confidential Containers](https://confidentialcontainers.org/) · [KServe](https://kserve.github.io/website/)
