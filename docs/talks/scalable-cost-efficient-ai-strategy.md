# Building a Scalable, Cost-Efficient AI Strategy with Red Hat AI

**11:05** · [Roy Nissim](https://www.linkedin.com/in/roy-nissim/) (Red Hat)

Hybrid inference strategy: AI gateway, validated model catalog, and high-performance serving with vLLM and llm-d — including how Red Hat runs this internally.

**Takeaways**

- Put a gateway between apps/agents and models (auth, quotas, routing, spend)
- Split premium closed vs self-hosted open by workload; make the open path the easy default
- Optimize with vLLM + llm-d patterns before buying more GPUs
