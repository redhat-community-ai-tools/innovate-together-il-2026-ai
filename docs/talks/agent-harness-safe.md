# Is Your AI Agent Harness Safe?

**11:35** · [Benjamin Kapner](https://www.linkedin.com/in/benjamin-kapner-ba75a11b5/) (Red Hat)

Find defects in skills, hooks, and MCPs with **harness-eval** before agents merge on their own. Static analysis + LLM review; evidence for safer agent workflows.

**Takeaways**

- Treat skills/hooks/MCPs as security-sensitive code, not docs
- Lint the harness as a graph (cross-file flows), not file-by-file only
- Pin MCP packages; gate merges on validated rules
