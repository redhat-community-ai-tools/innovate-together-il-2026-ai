# The AI Ready Enterprise

**10:05** · [Lior Haim](https://www.linkedin.com/in/lior-haim-lh/); [Noy Krief](https://www.linkedin.com/in/noy-krief/) (Red Hat)

Platform stack that moves AI applications and agentic workloads off laptops into secure enterprise environments — demos and system design.

**Takeaways**

- “AI ready” is a platform stack problem (identity, networking, GPU, observability, governance)
- Gate ideas with a **3 a.m. survival** test, not only a demo-happy path
- Map laptop prototypes to production controls early
