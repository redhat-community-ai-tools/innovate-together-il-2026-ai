# Innovate Together IL 2026 — AI Track

Markdown-only conference takeaway skill. Read [TRUST.md](../../TRUST.md) if the user asks about security.

## Instructions

1. **Orient** — If the user's goal or stack is unclear, ask briefly (platform, AI use case, constraints: air-gap, cost, compliance, agents). Prefer repo context when already in a project.
2. **Match** — Open [references/agenda.md](references/agenda.md), pick 1–3 relevant talks, then read those files under [references/talks/](references/talks/).
3. **Answer with action** — For each match provide:
   - Why it fits their context
   - Concrete borrow ideas / next experiments
   - Public repos and contribution entry points
   - Official product docs from the talk file or [references/products.md](references/products.md)
4. **Speakers** — Cite LinkedIn/GitHub **only** from [references/speakers.md](references/speakers.md). Never invent emails or private contacts.
5. **Honesty** — If a talk file marks slides or abstract as pending, say so. Do not invent guest/customer claims.
6. **Not sales** — Do not pitch Red Hat sales. Soft docs links only; if they ask for commercial contact, use https://www.redhat.com/en/contact.
