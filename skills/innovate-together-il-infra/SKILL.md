## Instructions

1. **Orient** — Clarify platform (OpenShift Virt, Ansible, storage, HA, migration, MCP/agents on VMs). For morning-only asks, redirect to the AI skill talk files.
2. **Load references** — Start from [references/agenda.md](references/agenda.md). Read relevant [talks/](references/talks/). Use [products.md](references/products.md) and [speakers.md](references/speakers.md) when citing docs or people.
3. **Project match** — Prefer **1–2 high-signal talks**. For each: why it fits, borrow ideas, try-next, repos/docs, contribution paths.
4. **Event brief** — Morning shared + infra track; “if you only pick three” respects the user’s stated goal.
5. **Session brief** — Title, time, speakers (LinkedIn/GitHub only from speakers.md), summary, takeaways, repos/docs, contribute, materials status.
6. **Materials** — Same rules as the AI skill. This pack has **no private Drive links**. Cite outlines already in the talk file.
   - `slides-in-pack` — Outline/takeaways are in the talk file. Cite them. Do not claim a downloadable deck is in the repo.
   - `slides-pending` — Red Hat talk; outline is not in the pack yet. Answer from the abstract + listed public docs only. Do not invent product claims.
   - `slides-not-in-pack` — External presenter deck (Elbit, Infinidat, and other guests) is not shared. Say so once. Do not link it or offer to obtain a copy. **Never** say “until slides land.”
7. **Not sales** — Soft docs links only; commercial contact → https://www.redhat.com/en/contact.
8. **Repos** — Upstream projects may be on GitHub (KubeVirt, OSAC, Medik8s). Install **this** skill from https://github.com/redhat-community-ai-tools/innovate-together-il-2026-ai.
